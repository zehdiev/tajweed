# Основи на теджуида

Учебно приложение по теджуид по книгата „Основни познания по Теджуид“ (превод на „Мусаххих ет-Теджуид“ от Сюлейман Хилми, 1330 г. х.).

## Какво има

- **Уроци:** 10 урока, подредени като в книгата, с арабски примери и обобщение „Запомни“.
- **Флаш карти:** термини, местопроизношения и видове медд.
- **Познай правилото:** пример от Корана с оцветена част; избираш кое правило действа в нея.
- **Тест:** въпроси по всеки урок и общ изпит от 20 въпроса.
- **Настройки:** светла/тъмна тема, екранът да остава включен, инсталиране на устройството.
- Работи без интернет след първото отваряне.

## Файлове

| Файл | За какво е |
|---|---|
| `index.html` | Цялото приложение |
| `manifest.webmanifest` | Име, цветове и иконки за инсталиране |
| `sw.js` | Работа без интернет |
| `icons/` | Иконки на приложението |

## Публикуване в GitHub Pages

1. Създай ново хранилище (repository) в GitHub, например `tejwid`.
2. Качи всички файлове от тази папка в него, като запазиш папката `icons`.
3. Отвори **Settings → Pages**.
4. В **Source** избери **Deploy from a branch**, клон `main`, папка `/ (root)` и натисни **Save**.
5. След около минута приложението ще е на адрес `https://<твоето-име>.github.io/tejwid/`.

## Инсталиране на телефона

- **Android (Chrome):** отвори адреса → Настройки в приложението → „Инсталирай приложението“, или менюто ⋮ → „Инсталиране на приложението“.
- **iPhone (Safari):** бутон „Сподели“ → „Добави към началния екран“.
- **Компютър (Chrome/Edge):** иконката за инсталиране в адресната лента.

## Обновяване

Когато промениш `index.html`, смени `VERSION` в `sw.js` (например `tejwid-v2`), за да получат потребителите новата версия.

## Забележка

Приложението е помагало. Правилното четене на Корана се усвоява при учител.
